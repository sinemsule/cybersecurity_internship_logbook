# Linux komut defteri

## Hafta 1
- pwd → bulunduğum klasörü gösterir
- ls → klasör içeriğini listeler (-l ayrıntı, -a gizli dosyalar)
- cd → klasör değiştirir (cd .. üst klasör, cd ~ ev klasörü)
- mkdir → klasör oluşturur
- touch → boş dosya oluşturur
- cat → dosyanın içini ekrana yazar
- cp → kopyalar
- mv → taşır ya da adını değiştirir
- rm → siler (geri dönüşü yok yani kalıcı)
- man → komutun kılavuzunu açar (çıkış için q seçtim)

## Dosya sistemi
- / → ağacın kökü
- /etc → ayar dosyaları
- /var/log → kayıt dosyaları
- /home → kullanıcı klasörleri
