File Analysis Commands
cat
Dosya içeriğini terminalde gösterir.

cat file.txt
head
Dosyanın ilk satırlarını gösterir.

head file.txt
tail
Dosyanın son satırlarını gösterir.

tail file.txt
file
Dosyanın tipini gösterir.

file file.txt
stat
Dosyanın metadata bilgilerini gösterir.

stat file.txt
man
Komutların yardım sayfasını açar.

man ls
