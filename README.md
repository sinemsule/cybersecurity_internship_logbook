# Staj Günlüğüm

Merhaba, ben Sinem Şule. Bilgisayar Mühendisliği öğrencisiyim.
Siber güvenlik odaklı bir staj yapıyorum.

## Amaç
Staj boyunca öğrendiklerimi, günlük çalışmalarımı ve projemi bu repoda belgelemek.

## Yapı
- `gunluk/` → her gün kısa çalışma günlüğü
- `haftalik/` → haftalık özetler
- `proje/` → ana projem
- `notlar/` → konu notları
- `toplanti/` → mentör toplantı notları
